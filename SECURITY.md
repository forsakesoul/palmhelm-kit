# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's **Report a vulnerability** feature on this repository (Security tab → Advisories → Report a vulnerability). Do not open a public issue for a security problem.

Do not include logs, device tokens, pairing codes, or session content in any report, public or private, unless a maintainer asks for them through the private channel.

## Supported versions

Only the latest tagged release receives security fixes.
